# Thematic Mapping Data Downloader - Tuljapur & Lohara Blocks

Automated pipeline for downloading and generating thematic map datasets (DEM, contours, slope, stream order, drainage density, LULC, soil depth, roads, rainfall climate metrics, and seasonal NDVI) for **Tuljapur** and **Lohara** blocks (Dharashiv / Osmanabad District, Maharashtra).

---

## 📁 Repository Structure

```
e:\MAPPING WORK\
│
├── mh1.geojson                     # Maharashtra village boundaries (Part 1)
├── mh2.geojson                     # Maharashtra village boundaries (Part 2)
│
├── prepare_aoi.py                  # Extracts and dissolves Tuljapur & Lohara blocks into AOI GPKG
├── tuljapur_lohara_map_data.py     # Main thematic map data download & processing script
├── requirements.txt                # Required Python packages
├── setup_env.bat                   # 1-click Windows setup script
│
└── map_data/                       # Output directory generated by scripts
    ├── aoi/
    │   ├── aoi_blocks.gpkg         # Block boundaries in GPKG format
    │   └── aoi_blocks.geojson      # Block boundaries in GeoJSON format
    ├── dem/                        # Copernicus GLO-30 DEM + 10m contours
    ├── slope/                      # Slope (degrees & percent)
    ├── streams/                    # D8 Strahler stream order & drainage density
    ├── lulc/                       # Esri 10m annual LULC + area statistics table
    ├── soil_depth/                 # ISRIC SoilGrids depth-to-bedrock
    ├── roads/                      # OpenStreetMap road network classification
    ├── rainfall/                   # CHIRPS mean annual, seasonal, CV, trend & time-series
    └── ndvi/                       # Sentinel-2 Cloud Score+ masked NDVI (annual, kharif, rabi)
```

## 🚀 Setup & Execution

### 1. Install Dependencies
Run the included batch script or manually create an environment:
```powershell
pip install -r requirements.txt
```

### 2. Prepare Area of Interest (AOI)
*Already run & verified.* If you ever need to re-generate the block boundaries from `mh1.geojson` and `mh2.geojson`:
```powershell
python prepare_aoi.py
```
- **Lohara Area**: ~543.20 km²
- **Tuljapur Area**: ~1500.72 km²
- Total AOI: ~2043.92 km²

### 3. Authenticate Google Earth Engine (GEE)
If you haven't authenticated Earth Engine on this machine yet:
```powershell
earthengine authenticate
```

### 4. Run Downloader

#### Run all themes:
```powershell
python tuljapur_lohara_map_data.py --project YOUR_GCP_PROJECT --themes all
```

#### Run specific themes:
```powershell
# E.g. DEM, slope, and rainfall:
python tuljapur_lohara_map_data.py --project YOUR_GCP_PROJECT --themes dem slope rainfall

# E.g. Roads, streams, and soil depth:
python tuljapur_lohara_map_data.py --project YOUR_GCP_PROJECT --themes roads streams soil_depth
```

#### Export to Google Drive instead of direct download:
```powershell
python tuljapur_lohara_map_data.py --project YOUR_GCP_PROJECT --mode drive
```

## 🗺️ Output Layers & Formats

| Theme | Layer / Output | Format | Source / Resolution |
|---|---|---|---|
| **AOI** | `aoi_blocks.gpkg` | GeoPackage | Dissolved village boundaries (Census/Local) |
| **Roads** | `roads_osm.gpkg` | GeoPackage | OpenStreetMap (classified by road hierarchy) |
| **LULC** | `lulc_esri_<year>.tif`, `lulc_<year>_area_table.csv` | GeoTIFF, CSV | Esri 10m Land Use Land Cover |
| **DEM** | `dem_aoi.tif`, `contours_10m.gpkg` | GeoTIFF, GeoPackage | Copernicus GLO-30 (30m) |
| **Slope** | `slope_deg_pct.tif` | GeoTIFF (2 bands) | Slope in degrees + percent |
| **Streams** | `streams_strahler.gpkg`, `drainage_density_grid.gpkg` | GeoPackage, CSV | D8 flow accumulation & Strahler stream order (WhiteboxTools) |
| **Soil Depth** | `BDRICM_cm_250m.tif`, `BDTICM_cm_250m.tif` | GeoTIFF | ISRIC SoilGrids 250m depth to bedrock |
| **Rainfall** | `rain_mean_mm_*.tif`, `rain_cv_pct.tif`, `rain_timeseries_aoi_mean_mm.csv` | GeoTIFF, CSV | CHIRPS Daily (5.5 km) |
| **NDVI** | `ndvi_annual_mean_*.tif`, `ndvi_kharif_median_*.tif`, `ndvi_rabi_median_*.tif` | GeoTIFF | Sentinel-2 L2A + Cloud Score+ (10m) |
